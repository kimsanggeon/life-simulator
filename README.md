# 내 인생, 1,000번 살아보기 — 인생 시뮬레이터

지금의 나(나이·연봉·모은 돈·결혼 여부)를 입력하면, 결혼·출산·실직·주가·집값이 **실제 한국 통계 확률대로** 일어나는 미래를 1,000번 돌려 10~20년 뒤 내가 어디쯤 있을지 보여 주는 웹 서비스입니다.

- **결과:** 한 문장 요약, 100명의 나, 세 명의 나(운이 나빴던·보통·좋았던 나의 인생 이야기), 회사 계속·이직·창업 비교, 운과 선택의 비율
- **공유:** SNS용 결과 카드 이미지 (연봉·모은 돈은 기본으로 숨김)
- **근거:** 화면의 모든 숫자는 출처·기준연도와 함께 `app/src/data/stats.json`에 있습니다. 공식 통계 / 통계에서 계산 / 모델 가정을 구분합니다.
- **검증:** 2012~2015년 실제 가구에서 출발해 10년 뒤 실제 분포와 비교하는 과거 검증을 화면 '자세히 보기'에서 볼 수 있습니다.

> 참고용 시뮬레이션이며 재무·투자 권유가 아닙니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `app/` | 웹앱 (React + Vite + TypeScript). 계산 엔진은 `app/src/engine/` |
| `app/src/data/` | 사이트가 쓰는 통계값(`stats.json`, `history.json`, `backtest.json`)과 남은 과제(`TODO.md`) |
| `data/raw/` | KOSIS·한국은행 ECOS·가계금융복지조사에서 받은 원자료 (사이트에는 올라가지 않음) |
| `prototype/` | 처음 기획 때의 게임형 프로토타입 |
| `CLAUDE.md` | 기획 원칙 |
| `배포_안내.md` | Vercel 배포 방법 |

## 실행

```bash
cd app
npm install
npm run dev
```

테스트는 `npm test`, 배포용 빌드는 `npm run build`.
